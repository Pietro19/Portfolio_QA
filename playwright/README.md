## 📌 Sobre o Projeto

Projeto de automação de testes utilizando **Playwright** com foco em:

- Testes End-to-End (E2E)
- Validações de UI
- Testes funcionais
- Testes de segurança
- Testes de usabilidade
- Testes de sessão
- Testes básicos de performance

O objetivo é demonstrar práticas reais de QA Automation aplicadas em cenários reais de aplicações web.

---

## 🧪 Aplicações Testadas

### 🎓 Inatel
Testes na página institucional incluindo:

- Validação de elementos da HOME
- Navegação entre páginas
- Verificação de botões e redirecionamentos
- Fluxos educacionais

### 🛒 SauceDemo
Testes completos de autenticação incluindo:

- Login positivo e negativo
- Validação de UI
- Testes de segurança
- Testes de usabilidade
- Testes de sessão e refresh
- Testes básicos de performance

- Playwright
